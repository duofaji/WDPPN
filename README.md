# WDPPN: An end-to-end attention network with learnable coefficient-wise wavelet shrinkage for robust seismic phase picking

This repository contains the implementation of **WDPPN**, a deep learning model proposed in our paper submitted to *Advanced Engineering Informatics*.

**Paper Title:** # WDPPN: An end-to-end attention network with learnable coefficient-wise wavelet shrinkage for robust seismic phase picking

**Status:** Submitted to *Advanced Engineering Informatics*


---

We have provided a **Sample Dataset** (subset of STEAD, INSTANCE, and Japan data) in this repository. Run the scripts in the WDPPN/test/ directory to test the seismic records from the sample dataset.

Please ensure you have the Python packages installed in the requirements file.

Because the complete benchmark dataset is large (approximately 53 GB), the full data archive is hosted separately and can be accessed at: https://drive.google.com/drive/folders/1711LMJbDR0HXZnTRQRgsf_p2DRBRa9tz?usp=drive_link.
